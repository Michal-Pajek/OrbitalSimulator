## Current status

This repository is a work in progress. The core model and parts of the simulation architecture are being developed iteratively.  
Some features are incomplete, experimental, or subject to refactoring.

## Goals

- simulate interactions between celestial bodies,
- generate visual animations showing the orbital motion of simulated bodies,
- support configurable scenarios,
- compare different numerical integration methods,
- provide a clean C++ architecture with testable components,
- gradually extend the model with body types, localization, scenario loading and collision detection.

## Technologies

- C++20
- CMake
- GoogleTest
- Visual Studio / MSVC

## Planned features

- scenario configuration files,
- multiple numerical integrators,
- body type catalog,
- collision detection,
- scenario editor,
- result recording and comparison.
